# JS Core Libraries 10 (핵심 자바스크립트 라이브러리 10선)

실무 웹 개발에서 가장 유용하고 자주 쓰이는 **10개의 핵심 JavaScript 라이브러리**를 엄선하여, 중복 없이 1:1 동작 데모와 **실무 활용 가이드 (언제 쓰면 좋은지)**를 제공하는 인터랙티브 쇼케이스입니다.

---

## 🌟 엄선된 10대 라이브러리 & 실무 활용성

| No | 라이브러리 | 핵심 기능 | 실무 활용 포인트 (언제 쓰면 좋을까?) |
|:---:|:---|:---|:---|
| **01** | **Chart.js** | 데이터 시각화 | 대시보드 매출 통계, 사용자 방문자 추이, 실시간 트래픽 그래프 |
| **02** | **SweetAlert2** | 고급 팝업/모달 | 브라우저 기본 alert/confirm 대체, 회원 탈퇴/삭제 최종 확인창 |
| **03** | **Day.js** | 날짜 및 시간 연산 | SNS 댓글 상대 시간 ("방금 전", "3일 전"), 프로모션 D-Day 계산 |
| **04** | **SortableJS** | 드래그 앤 드롭 정렬 | Trello 스타일 칸반 보드, 할 일 목록 우선순위, 이미지 노출 순서 변경 |
| **05** | **Marked + DOMPurify** | 안전한 마크다운 렌더링 | 기술 블로그 및 Q&A 마크다운 에디터, XSS 악성 스크립트 100% 방어 |
| **06** | **Canvas-Confetti** | 축하 폭죽 파티클 | 결제/주문 완료 축하, 회원가입 완료, 미션 달성 시 감성 극대화 |
| **07** | **QRCode.js** | 동적 QR 코드 생성 | PC 화면에서 모바일 접속 유도, 오프라인 결제/티켓/와이파이 링크 생성 |
| **08** | **CountUp.js** | 숫자 카운팅 모션 | 랜딩페이지 핵심 성과 수치 (누적 회원 수, 총 거래액, 만족도 99%) |
| **09** | **Typed.js** | 타자기 타이핑 효과 | 홈페이지 메인 헤드라인 슬로건 강조, AI/챗봇 대화 시뮬레이션 |
| **10** | **Leaflet.js** | 경량 오픈소스 지도 | 복잡한 API 키 없이 오프라인 매장/회사 위치 안내, 여행 경로 표시 |

---

## 🚀 로컬 실행 방법

브라우저에서 `index.html` 파일을 직접 더블 클릭하여 실행하거나, 로컬 서버를 통해 확인할 수 있습니다:

```powershell
# 프로젝트 폴더로 이동 후 실행
python -m http.server 4173
```

그 후 브라우저에서 `http://localhost:4173/codex생성/` 을 열어 확인합니다.

## 🛠 개선 사항

- **라이브러리 중복 제거:** 1개 라이브러리당 1개의 확실하고 독립된 데모 제공.
- **실무 활용성 가이드 추가:** 각 카드마다 [💡 언제 쓰면 좋을까?] 안내 영역 탑재.
- **가독성 향상:** 전체 기본 폰트 크기 및 카드 설명 폰트를 2pt 이상 확대하여 시원시원한 가독성 확보.
- **모든 기능 정상 동작 검증:** CDN 버전 및 스크립트 오류를 전면 점검하여 10개 기능 100% 동작 보장.
